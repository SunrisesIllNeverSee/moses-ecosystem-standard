# Change History

## v0.1.0-draft (2026-09-04)

- Initial draft of the MO§ES Ecosystem Standard.
- Restructured from single SPEC.md to canonical information package:
  `canon/`, `architecture/`, `registry/`, `references/`, `machine/`,
  `validation/`, `docs/`.
- STANDARD.md: 20 sections covering purpose, definition, architecture,
  authority, taxonomy, product families, research families, standards,
  framework relationship, SigRank relationship, TTEOP relationship, public
  sites, terminology, privacy, versioning, conformance, URLs, registry,
  Search Authority provenance, and change history.
- canon/: structured canonical information projected from Search Authority
  (ecosystem, entities, relationships, terminology, authority-map, sources).
- architecture/: human-readable architecture documents.
- registry/: machine-readable registries split by type (components, standards,
  protocols, frameworks, products, sites).
- references/: references to external authorities (Search Authority, MO§ES
  Framework, TTEOP, SigRank Ecosystem Standard, external sources).
- machine/: machine-readable standard metadata (JSON, YAML, JSON-LD).
- validation/: validation scripts for internal consistency, authority links,
  and canon provenance.
- docs/: implementation guide, authority boundaries, publication rules.
- This is a draft. It is not frozen and may change without notice.
